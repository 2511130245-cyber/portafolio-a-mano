¿Qué es CSS?

CSS significa Cascading Style Sheets. Se utiliza para definir el diseño y apariencia de una página web.

¿Qué podemos modificar con CSS?

  • Colores
  • Fondos
  • Tamaños
  • Espaciados
  • Bordes
  • Posición de elementos
