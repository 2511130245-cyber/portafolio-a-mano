¿Qué es HTML5?

HTML5 es una versión moderna del lenguaje HTML utilizado para crear y estructurar páginas web.

Etiquetas semánticas

HTML5 permite utilizar etiquetas que describen mejor la estructura de una página.

  • header
  • nav
  • main
  • section
  • article
  • footer

Multimedia

HTML5 permite incorporar contenido multimedia como audio y video directamente en una página web.
